Kavach — skeleton → production

The bones are built and they move (detect → decide → act → audit → attach). Here is how each "body part" turns the skeleton into a living, production-grade product.

Built (skeleton) Next (makes it a product) Later (makes it a company)

The body

🦴 Skeleton built

the core that already moves

  • 11-class detection, 99.7% on synthetic data
  • decision engine · token vault · tamper-evident audit
  • SDK + LangChain / MCP / OpenAI adapters · console · Docker · 52 tests

🧠 Brain next

make it smart, not just correct — the moat

  • IndicNER / fine-tuned MuRIL for real Tamil/Hindi script
  • the real labelled code-mixed corpus from pilot data (DPA)
  • confidence calibration; more languages (Telugu, Bengali…)

💪 Muscles next

fast & strong under load

  • async + batching; streaming detection for voice
  • latency SLOs (p50/p95), load testing, caching
  • small on-device model for ultra-low latency

✋ Hands next

grab onto every stack

  • more adapters: LangGraph, LlamaIndex, CrewAI, AutoGen
  • voice pipeline hooks (STT/TTS) — the biggest India market
  • JS/TS and Go SDKs; gateway plugins (Kong, Envoy, LiteLLM)

🦵 Legs next

stand & run anywhere

  • real ASGI service (FastAPI) behind a reverse proxy
  • Kubernetes + Helm, autoscaling, HA, CI/CD
  • multi-tenant isolation, config-as-code

❤️ Heart — the vault later

trustworthy enough for a bank

  • KMS/HSM-backed vault, RBAC on de-tokenization
  • mTLS, console auth, secrets management
  • threat model + pen-test; SOC2-style controls

🧬 Nerves later

observable & provable

  • durable WORM audit store; SIEM/Splunk export
  • metrics + traces + alerting; drift monitoring
  • one-click DPDP evidence & breach packs

😊 Face / skin next

visually appealing — what people see

  • React console (shadcn/Tailwind): policy builder, live stream, charts
  • landing page + 90-second demo video
  • polished docs site

🩺 Immune system later

never falls over

  • fail-safe modes, circuit breakers, graceful degradation
  • the benchmark as a CI regression gate

🗣️ Voice — go-to-market next

how the product gets heard (not a voice bot)

  • publish: PyPI + npm; open-source the benchmark
  • "Kavach Certified" mark for agents that pass it
  • design partners (NBFC collections / Indian voice-AI)

If you only do 5 things next

  1. Push to GitHub + CI + PyPI — instantly "real," backed up, installable. Still #1.
  2. React console + a 90-sec demo video — the visually appealing face a hiring manager / founder actually sees.
  3. FastAPI service + Docker/Helm — the "runs in production" credibility (legs).
  4. Open-source the real labelled benchmark — the brain, the moat, and the hireable artifact at once.
  5. A JS/TS SDK — so it attaches to the agent stacks most people actually use (hands).
On "voice": as a feature, guarding voice agents (STT/TTS) is your richest target market (Indian call-centre / collections AI). As go-to-market, "voice" means publishing and demos so people adopt it. Neither means Kavach becomes a talking assistant.
