How it works

An agent's risky moment is a tool call carrying user data. Kavach sits on it.

01

Attach

One wrapper on your tool call — SDK, LangChain, MCP, OpenAI, or voice.

02

Detect

Checksums (Aadhaar, card, GSTIN) + Indic NER, incl. spoken number-words.

03

Decide

Allow / mask / tokenize / block / escalate by destination trust.

04

Prove

Hash-chained, tamper-evident audit with a one-click DPDP report.

The same payload headed to an untrusted third-party tool.

Attach in one line

Hand your agent guarded tools — nothing else changes.

from kavach import Kavach, Trust
from kavach.integrations.langchain import guard_tools

kav = Kavach(trust={"crm_api": Trust.UNTRUSTED})
agent = create_react_agent(llm, guard_tools(kav, tools))
