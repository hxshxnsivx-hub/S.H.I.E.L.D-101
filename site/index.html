how it works

Sits on the tool call. Decides. Proves.

An agent's risk is the arguments it sends to a tool. Kavach intercepts them before dispatch.

01

Attach

One wrapper — SDK, LangChain, MCP, OpenAI, or voice STT/TTS.

02

Detect

Checksums (Aadhaar, card, GSTIN) + Indic NER, incl. spoken number-words.

03

Decide

Allow / mask / tokenize / block / escalate by destination trust.

04

Prove

Hash-chained audit + one-click DPDP evidence report.

one line

Attach to your agent, change nothing else

Hand the agent guarded tools. The LLM, the prompt, the graph stay the same.

from kavach import Kavach, Trust
from kavach.integrations.langchain import guard_tools

kav = Kavach(trust={"crm_api": Trust.UNTRUSTED})
agent = create_react_agent(llm, guard_tools(kav, tools))  # now guarded
