How it works

Sits on the tool call. Decides. Proves.

An agent's real risk is the arguments it passes to a tool. Kavach intercepts them before dispatch — the model, the prompt and the graph stay exactly as they were.

01

Attach

One wrapper — SDK, LangChain, MCP, OpenAI, or voice STT/TTS.

02

Detect

Checksums for Aadhaar, card and GSTIN, plus Indic NER — even spoken number-words.

03

Decide

Allow, mask, tokenize, block or escalate, by destination trust.

04

Prove

A hash-chained audit log and a one-click DPDP evidence report.

One line

Hand the agent guarded tools

Change nothing else. The firewall wraps the tools; the agent never knows it's there.

from kavach import Kavach, Trust
from kavach.integrations.langchain import guard_tools

kav = Kavach(trust={"crm_api": Trust.UNTRUSTED})
agent = create_react_agent(llm, guard_tools(kav, tools))  # now guarded
