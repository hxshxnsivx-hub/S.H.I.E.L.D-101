# Kavach Intro — FULL single continuous sequence (all 5 beats, no cuts)

One unbroken shot: sketchbook opens → worker sends private data → worry-clouds →
handwritten question + shield → paper morphs into the product. No scene cuts.

**How to get the length in Flow (important):** a single generation is ~8s. To keep
this as ONE continuous shot, generate the first ~8s, then press **Extend** twice to
continue the *same* take (same reference frame + seed) through the writing and the
morph. Flow joins them seamlessly — it stays one clip, no cut.

**Style lock:** add a clean frame of your existing clip (`f_01.png`) as the reference /
first image so the ink + cork-board + hand style carries through.

**Text:** keep ALL handwriting as illegible scribble so nothing garbles; type the real
words (`Aadhaar`, `What if it leaks?`, the italic line, the logo) as a crisp overlay in
your editor afterwards.

**Final frame:** set the last Extend's end-frame to a screenshot of your real dark hero
so the morph lands exactly on-brand.

## Pacing across the one shot (~20–24s via Extend ×2)

- **0–5 s** — worker + data boxes draw and flow into the monitor.
- **5–9 s** — camera pulls back; worry thought-clouds bloom around him.
- **9–10 s** — continuous glide across the page (acts as the transition, no cut).
- **10–16 s** — the hand writes the italic line and sketches the shield.
- **16–24 s** — shield ignites; paper morphs into the dark product hero; settle and hold.

If you only generate the single 8s (no Extend), it will be very fast — Extend is what
makes "all scenes, one sequence" actually breathe.
